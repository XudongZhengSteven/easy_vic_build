easy_vic_build.tools.hydroanalysis_func.mosaic_dem.merge_dems(input_dir, suffix='.tif', output_file='merged_dem.tif', srcSRS='EPSG:4326', dstSRS='EPSG:4326', **gdal_warp_kwargs)[source]

Merge DEM files in a directory into one raster using GDAL Warp.

Parameters:

  • input_dir (str) – Directory containing DEM files.

  • suffix (str, optional) – Filename suffix used to select DEM files.

  • output_file (str, optional) – Output raster path.

  • srcSRS (str, optional) – Source CRS string.

  • dstSRS (str, optional) – Destination CRS string.

  • **gdal_warp_kwargs (dict) – Additional keyword arguments passed to gdal.WarpOptions.

Returns:

The merged raster is written to output_file.

Return type:

None

Notes

Default Warp settings include cubic resampling, LZW compression, and multithreaded processing.
